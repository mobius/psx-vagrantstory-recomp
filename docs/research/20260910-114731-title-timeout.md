# 标题超时与New Game判据
参考源码 TITLE/TITLE.PRG/22C.c：菜单无按键1000帧后selectedOption=Timeout，跳转case3/4。case0 New Game设置D_80061068.zndId=1、mpdId=0，stateFlags.unkD=0；case3设置zndId=20、mpdId=0，case4设置zndId=2、mpdId=1，均unkD=1。
新运行会话读到场景字节0201，证明处于超时演出，不是New Game。无窗口加速缩短了人工工具交互窗口，所以不能把菜单后加载画面算作New Game证据。
probe_new_game.py使用正常Start输入，在调试接口刚可用时持有，检测0100与unkD=0后释放。没有直接改写游戏内存。
此前缓存与无缓存截图的差别尚不能排除场景选择/输入时间差，收回仅凭该比较归因原生缓存故障的结论；继续用同场景状态验证。
