# 术语
- recomp/静态重编译：将游戏机器码提前转换并编译为宿主代码。
- 反编译：从机器码还原源代码；匹配反编译要求重新编译后字节一致。
- BIOS：原主机的底层固件。
- 覆盖层 overlay：运行时加载到共享内存区域的不同代码。
- MIPS：PS1 CPU 使用的指令体系。
- 运行时 runtime：为重编译代码提供图形、声音等原主机行为的支持层。

- CMake：生成编译配置的工具。
- Ninja：执行编译任务的工具。
- C 代码分片：将大量生成代码拆成多个文件以分开编译。
- SHA1/SHA256：文件摘要，用于检查文件内容是否一致。
- 调度表 dispatch table：将原游戏地址映射到宿主函数的表。
- ISO9660：光盘文件系统格式。
- UTF-8/GBK：不同的文本编码方式。

- API 接口：程序之间读写状态或调用功能的约定。
- 显存 VRAM：存储画面、纹理等图形数据的内存。

- 动态库 DLL：运行时加载的本机代码文件，本项目用来承载额外转换的游戏代码。
- 解释执行回退：尚未转换的指令由运行时逐条执行，以便继续运行。
- CPS：将执行拆成可返回调度器的步骤，支持在原机时序边界处理事件；覆盖层必须与主程序采用同一种模式。

- AOT（Ahead of Time）：运行前提前编译。本项目将光盘PRG按已核对的地址生成本机代码。
- 候选函数入口：可能是函数开头的地址，须通过指令及控制流审计，不能直接等同已覆盖函数。
- 常驻代码：加载后长期留在内存中的程序片段。
- Lua：PCSX-Redux内置的脚本语言，本项目用它在本地采集对照截图。

- 函数中部入口：某些手写汇编会跳到函数内部标签执行，普通函数开头扫描可能漏掉；必须用实际调度证据和字节校验补齐。

- Git 子模块：仓库记录另一个源码仓库的固定提交，避免复制整个依赖历史或本地生成文件。
- Git 暂存区（index）：下一次提交实际包含的文件快照；提交审计读取这里的内容。
