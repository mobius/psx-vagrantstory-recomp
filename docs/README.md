# 文档索引

当前验收状态以根目录 [STATUS.md](../STATUS.md) 为准。research、plan、impl、architecture 保留按时间戳命名的迭代记录，其中早期推测可能被后续实测纠正。

- research：来源、版本匹配、输入/脚本诊断与有限样本覆盖报告。
- plan：阶段目标、未完成项和最新 handoff 恢复步骤。
- impl：每轮代码生成、构建和运行结果。
- architecture：依赖、接口、文件边界与提交布局。
- [glossary.md](glossary.md)：交互中使用的技术术语。

截图、游戏字节捕获、原生程序、记忆卡和快照只在本地忽略目录，不随文档提交。
